# Source Observations

## OpenCode

Source: https://github.com/anomalyco/opencode

The official repository describes OpenCode as an open-source coding agent. The current repository page shows a large TypeScript/MDX codebase with dedicated packages, `.opencode`, specifications, SDKs, and documentation. The page identifies an MIT license and documents agents, tools, skills, providers, sessions, and a web/server interface as relevant concepts for integration.

## Presenton

Source: https://github.com/presenton/presenton

The official repository describes Presenton as an open-source AI presentation generator and API under Apache-2.0. Its repository page documents self-hosted and desktop operation, support for Ollama, LM Studio, OpenAI-compatible providers, Anthropic, Gemini, and other providers, as well as prompt/document/PPTX-driven generation, manual editing, editable PPTX export, PDF export, templates, themes, charts, and an API layer. The visible structure includes `electron`, `servers`, `templates`, `docs`, and Docker-related files.
